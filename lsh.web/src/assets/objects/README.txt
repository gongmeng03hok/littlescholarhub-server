Drop-in artwork folder for question illustrations.

Put PNGs here named after the object, e.g. apples.png, sunrise.png, dinosaurs.png.
They are picked up automatically by src/constants/questionImages.ts — no code
change needed. Filenames and image prompts: docs/QUESTION_IMAGE_PROMPTS.md

Style: soft 3D Pixar-style clay render, single subject, centred, plain warm
cream background (#f7efe2-ish), soft studio light, gentle shadow, NO text.
Square, 600x600 or 1024x1024, PNG.
